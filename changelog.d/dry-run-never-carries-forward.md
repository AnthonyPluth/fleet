`agent-review.yml` with `dry-run: true` (the Self-test's calls) never carries a verdict forward: both reviews' Gather steps pass `DRY_RUN`, and `agent_review.py plan` then reviews a push that only merges main instead of copying the last review's pass. The dry runs read the pull request's real last review, so on a risky agent's pull request whose second review had passed, a merge of main that left its own change byte for byte as reviewed made every risky dry-run case pass "Carried forward from the review of <sha>" in place of its stub answer, and the Self-test's "Second review (dry run) verdicts" failed on the labelled case (as on the v5.0.0 release pull request, #137, the first since changelog fragments where a merge of main touched none of the pull request's files: before them every pull request changed `CHANGELOG.md`, and so did nearly every merge of main, so nothing was carried). A real run (`dry-run` false, the default) carries a passing review forward exactly as before. Tests: `tests/test_agent_review.py` (`Plan`: a dry run of either review reviews such a push, incrementally, while `DRY_RUN` false or unset still carries it) and `tests/test_agent_review_workflow.py` (both Gather steps pass `inputs.dry-run`). What apps do: nothing; `dry-run` is for fleet's Self-test only.
